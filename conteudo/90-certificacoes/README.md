# Certificações

Índice de certificações de segurança organizado por área de conhecimento. Cada fornecedor tem
um arquivo próprio.

## Regra de verificação

Todo campo numérico (pesos por domínio, custo, validade, número de questões) exige fonte
primária do próprio fornecedor, acessada e registrada. Sem fonte primária, o campo recebe
literalmente `NAO CONFIRMADO em fonte oficial`.
